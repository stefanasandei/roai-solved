# Poland NOAI 2025

## Tasks
As part of the first stage of the Olympiad, participants will face the following challenges:
1. **Coin Counting Machine** - Coin detection using computer vision models.
2. **Hallucination Detection** - Detecting hallucinations of language models in answers to questions.
3. **ECG Signal Disorder Detection** - Detecting anomalies in ECG data.
4. **Noise in Data Labels** - Training models with noisy labels.
5. **Hidden Subsequences** - Identifying dependencies in binary character sequences.

In the second stage, participants competed by solving the following tasks:

1. **Non-Normal Distribution** - Removing and classifying different types of noise in images.
2. **Credit Taking** - Finding directions in the data space that most effectively change classifier decisions.
3. **Source Extraction** - Selecting embeddings useful for source text retrieval.
