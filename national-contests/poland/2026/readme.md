# Poland NOAI 2026

## Tasks
As part of the first stage of the Olympiad, participants will face the following challenges:
1. **Convolutional filters** - An introduction to one of the most important methods in computer vision
2. **Multi-label classification** - Processing images containing different objects
3. **Whisper or scream** - Classification of audio data
4. **Semantic change** - Analysis of word embeddings with respect to meaning change
5. **Multispectral segmentation** - Segmentation of satellite images
