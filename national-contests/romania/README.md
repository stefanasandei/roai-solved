# Romania AI Olympiad

Two contests with separate roadmaps:
- ROAI: main olympiad, with selection for CEOAI and IAIO
- ONIA: spawned from ROAI, selection for IOAI

ROAI's contests are held on https://judge.nitro-ai.org/competitions

ONIA's contests are held on https://platform.olimpiada-ai.ro/en/problems

ROAI's olympiad website is https://olimpiada.nitro-ai.org/

ONIA's olimpiad website is https://olimpiada-ai.ro/

Each has similar phases:
- local: per city
- regional
- national
- selection camp: final contests with around 20 students to select the 4/8 students for each international olympiad
